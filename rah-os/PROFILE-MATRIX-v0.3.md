# RAH OS v0.3 profile matrix

| Profile | Boot parameter | Startup |
|---|---|---|
| Standard | `rah.profile=standard` | KDE + Raven Command Center |
| Nova VI | `rah.profile=nova` | Full-screen controller shell |
| Ghost & Rescue | `rah.profile=rescue` | Recovery tools menu |
| Forge | `rah.profile=forge` | Raven + developer terminal |
| Arcade Nexus | `rah.profile=arcade` | Controller-first RetroArch shell |
