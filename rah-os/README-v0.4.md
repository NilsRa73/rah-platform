# RAH OS Raven v0.4 Candidate

Built from the v0.3 Stable boot/runtime baseline.

## v0.4 focus

- Black/gold Raven Command Deck
- Controller/TV-friendly fullscreen mode
- Read-only AI Dock for detecting LM Studio, AnythingLLM and Ollama on local ports
- Existing Standard, Nova, Rescue, Forge and Arcade profiles retained
- Existing Live USB acceptance and Ghost safety gates retained

## Safety

v0.4 remains a candidate until a real-hardware Live USB PASS has been reviewed.
No arbitrary Raven shell endpoint is added. AI Dock only checks local TCP ports.
No automatic disk writing or automatic promotion to Stable is enabled.
