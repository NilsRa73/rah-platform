# RAH OS v0.9 — Omen Candidate

This candidate turns the Omen laptop into RAH OS Reference Machine #1 without touching partitions.

## One-click
Run `START-RAH-OS-v0.9-OMEN-CANDIDATE.cmd`.

It installs:
- one RAH OS START HERE shortcut
- Controller/Desktop mode switch
- Omen health check
- Raven Command Wheel entry
- ChatGPT entry
- optional Local AI check

It preserves prior v0.3/v0.8 work and does not format USB/SSD or replace Windows.

## Stability gate
Before ISO promotion:
1. Reliable boot
2. Network
3. Audio
4. Bluetooth
5. Raven Bridge / Command Wheel
6. Controller fullscreen mode
7. Desktop mode return
8. ChatGPT
9. Local Gemma remains optional and non-blocking
10. Only then build/promote ISO
