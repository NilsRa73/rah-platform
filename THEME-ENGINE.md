# RAH Theme Engine v1

Theme Engine is a presentation layer for the same Daily Driver runtime. It does not fork data, Chronicle, Council, Investigator or Devices state.

## Presets

| Theme | Profile | Intended use |
|---|---|---|
| Raven Gold | command | Daily default |
| Picasso | art | show / presentation |
| Steam / Game | game | controller / sofa / TV |
| Facebook Investigator | analysis | recovery / OSINT |
| Egypt / Horus | command | cinematic RAH command style |
| Cyber Neon | lab | local AI / agent lab |
| Clean Windows | work | dense everyday work |

## Self-review

Every palette is audited for body-text/background contrast and accent/background UI contrast. The audit and profile recommendation are visible through the Insights data.

## Steam

Steam itself is not modified. Selecting Steam / Game changes the Daily Driver layout scale and palette. A dedicated action launches `steam://open/bigpicture` through the registered Steam protocol handler.
