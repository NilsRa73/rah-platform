How it works

Behind the scenes

A small managed VPS such as Hetzner CX43 costs €15.99/month before tax, public IPv4 and backups (November 2026). Static hosting can start free with Cloudflare Pages or GitHub Pages.

Our revenue comes from setup, design, monitoring, support and managed service — not a claim that we built the underlying network.

Safety and limitations

Each client requires a documented agreement, access control, restoration plan, data-processing terms where necessary, and a clear path to their own domain and data. No unapproved automated website changes.

RAH Cloud is a service concept being validated, not a live production platform accepting payments.
