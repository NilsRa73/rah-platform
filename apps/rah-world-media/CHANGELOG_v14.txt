RAH World Media 14.0 — RAVEN WORLD GRID
========================================

CORE
- Promotes the canonical World Media line from v12 to v14.
- Keeps Raven Sync Deck receiver/queue/sync behavior.
- Shared user data remains under C:\RAH\IPTV.

TV CATALOG RECOVERY
- fetch_tv_json now keeps a stale-cache fallback.
- Forced HENT KANALER refresh falls back to the last known good catalog if the provider/network is unavailable.
- channels.json + streams.json remain critical.
- countries.json, categories.json and logos.json are optional metadata; failure no longer empties the entire TV list.
- Degraded metadata mode is shown in the status line.

RAVEN WORLD GRID
- Country and world HLS pools increased to as many as 500 entries.
- Visible presets: 16 / 36 / 64 / 100 / 256 / 500.
- LIVE LIMIT is independent from visible tiles; default 16, choices through 256.
- STANDBY tiles do not start a decoder until activated.
- Activating a standby tile retires the oldest active tile when the live cap is reached.
- NEXT BANK rotates through the source pool.
- AUTO 10s rotates banks every ten seconds.
- CLEAN hides tile captions.
- XREAL 32:9 changes grid geometry for ultrawide viewing.
- Selecting a live cap above 64 shows a local load warning.

500-VISIBLE FIX
- Fixed the case where 500 WORLD could appear to contain only the 16 active live decoders.
- World tiles are now drawn from the full stream catalog, while HLS compatibility only controls which tiles can consume LIVE LIMIT slots.
- Standby tiles now remain visibly identifiable with logo/initials, index, channel and country.
- Status VISIBLE is derived from the actual tile count in the DOM, not from the live decoder count.
- Added practical LIVE LIMIT steps 24 / 32 / 48 between the existing presets.

MOSAIC FAST-RECOVERY HOTFIX
- Dead Mosaic streams no longer consume a LIVE LIMIT slot after recovery candidates are exhausted.
- Empty live slots refill automatically from other standby tiles.
- Auto-heal avoids assigning a stream URL that is already active in another tile.
- Known-good / non-geo-blocked / 24-7 HLS sources are prioritized for the first decoder bank when local health history is available.
- Stalled playback recovery begins after about 14 seconds instead of 22 seconds, with shorter HLS manifest/level retry windows.
- Mosaic status now separates OK and STARTING streams so startup failures are visible immediately.

FAST MOSAIC + MENU AUDIT
- First live bank now starts in small parallel batches instead of a long per-tile stagger.
- New 8.5s startup watchdog replaces feeds that never become healthy; established feeds use an 11s stall threshold.
- Stale HLS callbacks are ignored with per-video generation tokens so an old failed stream cannot replace a newer healthy assignment.
- Replacement feeds start faster and dead slots refill sooner.
- Hover preview delay reduced and preview HLS buffers/timeouts tightened for quicker feedback.
- Contract tests now enumerate inline menu/toolbar handlers and fail the build if any onclick/onchange target is missing.
- Layout deck remains 10 modes and is counted by the rendered-page test.

MOSAIC / LIVE PREVIEW HOTFIX
- Fixed 16/36/64/100 Mosaic opening only the currently selected country catalog; all grid presets now open from the full WORLD catalog, matching 256/500 behavior.
- Deduplicates world stream URLs before building the 500-tile pool.
- Prioritizes obvious .m3u8 sources for the first LIVE LIMIT bank so multiple live tiles start faster.
- Browser HLS detection now accepts opaque HTTP(S) live-manifest URLs while excluding obvious DASH/direct-file formats.
- Hover preview and theater playback share the same improved HLS URL detection.

LIVE HEALTH / WORLD SCAN UPDATE
- Added per-tile healthy/healing/dead state indicators.
- Added a watchdog for stalled live HLS playback.
- Fatal or stalled URLs are temporarily quarantined instead of being selected again immediately.
- Dead tiles auto-heal to another available stream after retries fail.
- The replacement source is retained by the tile, fixing the old behavior where a later click could retry the original failed URL.
- Added ROTATE LIVE to scan a large visible wall in decoder-sized banks.
- AUTO 10s now rotates live banks for grids larger than LIVE LIMIT.
- Large-grid DOM creation uses a DocumentFragment and staggered live starts to reduce UI spikes.
- Added NEW SCREEN for multi-monitor/projector use and keyboard shortcuts 1-6/R/A/X/C/F.

10-LAYOUT DECK
- Added an integrated LAYOUTS menu with ten persistent visual modes.
- Modes: RAH GOLD, STORM TV + RADIO, RGB PULSE, NORDIC ICE, CYBER RAVEN, NEWSROOM, CINEMA BLACK, RETRO CRT, GLASS NEON and XREAL ULTRAWIDE.
- Layout selection is stored locally in the browser and reapplied when Media Wall reopens.
- World Grid column geometry can react to the selected layout, while LIVE LIMIT stays independent.
- Layout menu is available both from the main Media Wall header and while a World Grid is open.
- Fixed an accidental Media Wall keyboard handler that had landed in Remote Deck; keyboard shortcuts now live in the correct page.

MENU / SELF-MAINTENANCE UPDATE
- Added persistent BACK TO MENU and CLOSE GRID controls.
- Esc or M returns from the World Grid to the Media Wall menu, including after fullscreen exit.
- Added built-in --selftest with package/runtime/cache/network and 500-visible contract checks.
- SELFTEST.cmd now runs the built-in selftest and verifies MANIFEST.sha256 when present.
- Added SELF-IMPROVE.cmd / --self-improve for safe local maintenance: invalid cache backup/removal, public catalog refresh, stale health-cache pruning, and post-selftest.
- Self-improve does not rewrite application source or Windows settings.

RAVEN SMART CLUSTER INTEGRATION
- Merged the trusted-LAN TV Worker feature line into the newer World Grid/menu/selftest line instead of replacing either feature set.
- Added token-protected /cluster, /cluster/heartbeat, /cluster/state, /cluster/clients and /cluster/next routes.
- HOVED-PC sends assignments only; workers fetch HLS directly and use their local browser/TV decode pipeline.
- Per-worker slot range is 1–12 with a conservative default of 4.
- AUTO TUNE probes 2/4/6/8/10/12 streams and falls back below 75% healthy playback.
- Added Cluster Nodes status window and Remote Deck TV WORKER / TOGGLE CLUSTER / NEXT CLUSTER controls.
- Smart Cluster never auto-enables trusted-LAN exposure after restart.
- Fixed the earlier Smart Cluster implementation so toggling the cluster cannot create duplicate receiver/cluster registry timers.
- Built-in selftest and CI now cover both World Grid and Smart Cluster contracts.

SAFETY
- Heavy World Grid playback remains user initiated.
- No DRM/paywall/geoblocking bypass is added.
- Trusted-LAN receiver mode remains explicit and token protected.
