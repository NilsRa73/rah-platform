RAH World Media 12.0 — RUN CHECKLIST

RUN FIRST
1. START-HER.cmd

OPTIONAL
- INSTALL.cmd — install under C:\RAH\WorldMedia\12.0 and create shortcuts
- SELFTEST.cmd — syntax/network/preflight checks
- DIAGNOSTICS.cmd — full diagnostics JSON
- REPAIR.cmd — safe dependency repair
- UNINSTALL.cmd — remove app, preserve C:\RAH\IPTV user data

SYNC TEST
1. Click RECEIVER and explicitly choose trusted LAN only if needed.
2. Open the copied tokenized Receiver URL on two devices.
3. Use NAME DEVICE on each receiver.
4. Confirm RECEIVERS shows both online.
5. Broadcast one TV/radio item. Both should schedule the same start time.
6. Press SYNC NOW to re-align them. Small browser/network drift is normal.
7. Test + QUEUE -> QUEUE NEXT -> STOP.

DO NOT
- Do not port-forward the Remote/Receiver port.
- Do not expose the receiver token publicly.
