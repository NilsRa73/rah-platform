RAH World Media 14.0 — RUN CHECKLIST
======================================

MAIN
1. Double-click START-HER.cmd.
2. Wait for PRECHECK / SELFTEST / POSTCHECK.
3. TV tab should populate automatically.
4. If the TV list is stale or empty, click HENT KANALER once.
5. Open MEDIA WALL and test 16 tiles first.
6. Confirm the status says VISIBLE close to the selected preset and LIVE stays at the chosen decoder limit.
7. Then test LIVE LIMIT 24 -> 32 -> 48 -> 64 gradually; stop increasing when playback or UI becomes unstable.

OPTIONAL
- INSTALL.cmd — install under C:\RAH\WorldMedia\14.0 and create shortcuts.
- DIAGNOSTICS.cmd — write support diagnostics.
- REPAIR.cmd — repair runtime files without deleting C:\RAH\IPTV user data.
- UNINSTALL.cmd — remove the v14 program folder; shared favorites/history stay preserved.

WORLD GRID
- Visible presets: 16 / 36 / 64 / 100 / 256 / 500.
- 500 WORLD should visibly show hundreds of named/logo standby tiles even when LIVE LIMIT remains 16.
- Default LIVE LIMIT: 16.
- NEXT BANK rotates to the next visible group.
- ROTATE LIVE keeps the same large wall but moves the active decoder bank.
- AUTO 10s uses live-bank scanning when visible tiles exceed LIVE LIMIT.
- Watch the status line: OK = healthy live feeds, HEALED = automatic replacements, HOLD = temporarily quarantined bad URLs.
- NEW SCREEN opens another copy for a second display.
- CLEAN hides captions.
- XREAL 32:9 widens the grid geometry.
- 256/500 are display-density targets, not a promise that every stream can decode simultaneously.

SUCCESS
- SELFTEST: PASS (warnings may remain for optional VLC/Windy features).
- TV channel count is non-zero or a previous cached catalog is loaded.
- Media Wall opens and LIVE count never exceeds the selected limit.
- A broken/stalled HLS tile can heal to a replacement without restoring the failed URL on the next click.

DO NOT
- Do not expose the token-protected receiver port to the public internet.
- Do not use World Media to bypass DRM, paywalls or geo restrictions.
