# RAH AI Investigator v1.0 RC1

Local-first personal account-recovery and authorized personal-OSINT module for RAH Raven.

## Status

**Candidate / RC1 — not Stable yet.** The HTML/JavaScript syntax gate passes, but Windows/Kali runtime testing remains open before Stable promotion.

## Core capabilities

- import extracted Facebook/Google/Yahoo and other personal archives
- extract emails, phone numbers, URLs and usernames
- identity seeds and aliases
- Account Matrix with recovery status
- identity clustering and relationship graph
- source-file evidence links and timeline
- Case JSON and CSV export
- local Agent Job workflow

## Optional free agent profile

- Sherlock — public username discovery
- PhoneInfoga — phone public-footprint / metadata workflow
- SpiderFoot — **passive mode only**

The recovery agent intentionally excludes password guessing, credential stuffing, phishing, session theft, 2FA bypass and exploit scanning.

## Package

Download and extract `RAH-AI-Investigator-v1.0-RC1-Full-Bundle.zip`, then run `RUN-ME-FIRST-RAH-INVESTIGATOR.bat` on Windows.

The bundle contains the HTML application, Windows/Kali helper scripts, archive extractor, local agent, self-test, version manifest and Candidate Gate.
