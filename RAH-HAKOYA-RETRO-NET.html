Håkøya RetroNet

Windows + MAME + RetroArch + Batocera + Android/Smart-TV samlet i ett lokalt retrospillnett — nå med Walkie-Talkie Wi-Fi og RAH Bifröst Bluetooth Fabric.

MAMERetroArchBatoceraAndroid TVWalkie-Talkie Wi-FiBifröst Bluetooth

PC / Arcade

MAME + RetroArch, fullskjerm RAH-meny, controller-/arcade-støtte og én snarvei: RAH RETRO.

Batocera

USB/SSD-boot for eldre PC-er og dedikerte stasjoner, med RAH-profil og Supernett-kobling.

Android / TV

Lett klient for mobil, Android TV og projektor. Lokal emulering eller streaming fra sterkere PC-node.

Håkøya Supernett-server

  • Profiler, favoritter, metadata, artwork og highscores
  • Lobby: hvem spiller nå?
  • Save/sync der støttet
  • Install-manifest og node-status
  • RAH Walkie-Talkie Wi-Fi med RETRO/NABO/TEKNISK-rom
  • RAH Bifröst som Bluetooth registry/gateway

RAH Bifröst Bluetooth Fabric

Et RAH-lag over Windows Bluetooth API-er og Linux/BlueZ. Først bygger vi en bedre kontrollflate, ikke en ny kernel-driver.

  • Samlet oversikt over adaptere og enheter på godkjente noder
  • Pair / connect / forget fra én RAH-meny
  • Friendly names, batteri/signal, controller-profiler og auto-reconnect
  • BLE/GATT-sensor gateway og kompatible Classic/RFCOMM-datafunksjoner
  • Konfliktvarsling når samme enhet allerede brukes på en annen node
  • Senere: input-forwarding, audio-routing og andre nettverksbroer

Pool betyr registry + gateway: fysisk radio forblir lokal, mens støttede funksjoner kan eksponeres over Håkøya Supernett.

RAH Retro One-Click Candidate

Første installasjonspakke skal opprette C:\RAH\Retro\, finne/installere godkjente emulatorer, teste controller/Bluetooth/lyd/skjerm, finne Håkøya-serveren, lage RAH RETRO-snarvei og avslutte med tydelig PASS / CHECK / FAIL.

ROM-policy

RAH distribuerer ikke kommersielle ROM-er eller BIOS-filer. Brukeren legger inn egne lovlige dumps, lisensiert eller lovlig frigitt innhold.

Én meny. Én installasjon. Mange gamle maskiner. Ett lokalt spillnett.
