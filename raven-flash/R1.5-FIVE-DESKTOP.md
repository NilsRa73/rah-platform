- The Raven Openbox session opens five-desktop.html#kjell on login.
- Five profiles: Kjell Senior, Nils RAH, Picasso Wheel, Aurora Lounge, Raven Rescue.

- The original Raven start page includes a link to Five Desktop.

- Build ISO in isolated Linux CI. Require checksum, BIOS/UEFI, QEMU login/session, VirtualBox, Ventoy and physical laptop evidence before accepting.

Safety: no disk format, Windows BCD/EFI, firmware, bootloader, stable version or RAH GOLD changes.

Rollback: revert the candidate branch; original R1.5 gold base branch remains untouched.
