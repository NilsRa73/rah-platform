# RAH Raven Flash R1.5.0 — Kjell Senior Edition (source candidate)

Dedicated senior-friendly **offline start page**: /opt/raven-flash/kjell-senior.html.

- Larger, accessible controls and readable Norwegian descriptions; clock/date, larger fonts, optional dark mode, keyboard numbers 1–8
- Eight useful functions: email launcher + unsent compose draft, news, weather links, notes with .txt export, radio/TV links, private photo preview, help, and switch to five other desktop choices
- Local HTML and CSS, no CDN, fonts, online images, or background requests
- On Raven Flash live login, the Openbox session launches Kjell Senior first
- Five Desktop chooser, RAH Gold/Håkøya, and existing browser session features remain separate and available in the menu
- No login credentials in our page and no automatic sending of messages
- Chromium profile on live USB is RAM-backed; exported notes may be lost if saved to volatile disk. Save .txt to durable storage before reboot

## Safe handoff
The separate Windows ZIP preview includes START-HER.cmd (no install), INSTALLER-F.cmd (new directory only, SHA-256 readback) and opt-in KJELL-LAPTOP-SETUP.cmd (Documents copy + desktop shortcut).
The portable preview **does not contain a bootable ISO**. Copying HTML to F: does not create a Ventoy boot choice.
