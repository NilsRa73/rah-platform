# RAH OS / Raven Flash R1.5 Candidate

Dato: 9. november 2026.

R1.5 bygger videre på den verifiserte R1.4-kildegrenen uten å endre Windows,
RAH GOLD, intern disk, EFI/BCD eller USB. Kandidaten samler den slanke R1.4-basen
med et lokalt Håkøya/Raven-skrivebord, idéblokk og en sannferdig lokal statusvisning.

## Ferdigkriterier

- [x] Kilde og byggeoppskrift oppdatert til R1.5.
- [x] Håkøya/Raven-skrivebord ligger lokalt på ISO-kilden og er første GUI-side.
- [x] Raven-launcher er tilgjengelig fra skrivebordet.
- [x] Idéblokk kan skrive, lagre og gjenåpne data i Chromium-profilen i samme live-økt.
- [x] Nettverksstatus måles lokalt via NetworkManager.
- [x] Lokal AI-status måles bare mot 127.0.0.1:1234 og bruker FOUND / API_NO_MODEL / NOT_FOUND, aldri oppdiktet PASS.
- [ ] GitHub Actions: R1.5 ISO-bygg + SHA-256 PASS.
- [ ] GitHub Actions: BIOS/UEFI QEMU + login + skrivebord/browser-session PASS.
- [ ] VirtualBox fysisk/GUI-akseptanse fra produsert ISO.
- [ ] Fysisk HOVED-PC: boot, GPU, Ethernet/Wi-Fi og brukerflyt.
- [ ] Fysisk USB/Ventoy-handoff hvis den skal brukes som akseptansemedium.

En CI-PASS er ikke fysisk HOVED-PC-PASS. VirtualBox/QEMU og fysisk maskin skal
rapporteres separat.

## Første brukerflyt

1. Boot Raven Flash R1.5.
2. LightDM logger inn brukeren `rah` automatisk.
3. Openbox starter lokal statusmåling og Håkøya/Raven-skrivebordet.
4. Skriv i Idéblokk og trykk **Lagre idé**.
5. Åpne **Raven launcher** eller **Systemstatus**.
6. Win+S regenererer status fra lokale målinger.

Live-profilen er RAM-basert. Uten separat persistens forsvinner idéblokk og
Chromium-data ved omstart. Det er tilsiktet i denne kandidaten og skal ikke
presenteres som permanent lagring.
