RAH OS USB Prep v0.1
====================

Double-click START-RAH-OS-USB-PREP.cmd.

The tool does NOT write to disks. It only:
- opens the successful GitHub Actions build,
- lets you select the downloaded ISO,
- verifies SHA-256,
- opens the Rufus website after verification.

Authoritative ISO:
RAH-OS-Raven-v0.1-amd64.iso
SHA-256:

GitHub Actions run:
https://github.com/NilsRa73/rah-platform/actions/runs/34187411973

Safety:
When using Rufus, identify the USB key by brand and capacity before pressing START.
Do not select the internal SSD.
